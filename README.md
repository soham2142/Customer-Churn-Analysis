# Customer Churn Analysis & Retention Dashboard

## Project Overview
This project focuses on analyzing customer churn patterns and understanding the factors that influence customer retention.

The objective is to explore customer data, identify churn-prone customer segments, and derive business insights that can help improve customer retention.

## Objectives
- Analyze customer churn patterns.
- Identify customer segments with higher churn risk.
- Explore the relationship between customer tenure, contract type, and churn.
- Visualize important customer behavior trends.
- Provide insights and recommendations for customer retention.

## Tools & Technologies

- Pandas
- NumPy
- SQL
- Matplotlib
- Seaborn
- Power BI
